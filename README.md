# GIS-Portfolio
This portfolio contains a collection of GIS projects demonstrating spatial analysis, digital cartography, terrain analysis, and geospatial data visualization. These projects were completed as part of Geographic Information Systems (GIS) courses at the University of Victoria.

## Projects
### Local_Maps
- Collected and prepared spatial data from open data sources, while learning how to check data usage rights and properly credit sources.
- Converted and organized different spatial data formats (CSV, KML, and GeoJSON) in ArcGIS Pro, including working with coordinate systems and creating map layouts.

### Snow_Analysis
- Used ArcGIS Pro tools to analyze geographic data by querying features, joining datasets, and finding relationships between different map layers.
- Applied vector and raster analysis techniques, including attribute queries, spatial queries, raster calculations, and reclassification to create meaningful maps.
